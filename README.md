Project description:
This project is a Management System developed in C to make it easier for an organization to manage its day-to-day information. Instead of keeping employee, budget, supplier, and asset information separately, the system brings everything together in one program.
The system allows the user to add, view, and search information about employees, budgets, suppliers, and assets. It also includes a reporting section that gives useful summaries, such as salary information, budget spending, supplier details, and asset values.
The main goal of the project is to create a simple and user-friendly system that helps keep information organized and easy to access. It also demonstrates how C programming concepts such as functions, structures, arrays, loops, and decision-making statements can be used to create a practical real-world application.

system features:
1. Add Employee – Allows the user to enter a new employee’s ID, name, department, basic salary, housing allowance, and transport allowance.
2. Display Employees – Shows all employees and their stored information.
3. Search Employee – Allows the user to find an employee using their employee ID.
4. Calculate Salary – Calculates the employee’s total salary using the basic salary and allowances.
5. Update Employee – Allows existing employee information to be changed.
6. Delete Employee – Removes an employee from the system.
7. Asset Management – Keeps track of company assets assigned to employees.
8. Menu System – Provides an easy-to-use menu so the user can choose what action to perform.
9. Data Validation – Checks that information entered by the user is valid before storing it.
10. Employee Records Management – Keeps employee information organized and accessible within the system.

compilation instructions:
To run the Employee Management System, open the project in a C programming environment such as Code:Visual Studio Code. Make sure that all the required source files and header files are saved in the same project folder. Open the main C file and compile the program to check for any errors. If the program compiles successfully, run it and the main menu will appear, allowing the user to access the different employee and asset management features.

how to run the system:
Compile the program first, run it, then use the menu to access the different features of the Employee Management System.
